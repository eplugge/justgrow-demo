# Just Grow v13

Calm Studio, bijgewerkt volgens `website aanpassingen 6-9-2026.docx`.

Open `index.html` voor de volledige website. De zes pagina's gebruiken normale
HTML-bestanden, met afbeeldingen, CSS en JavaScript in `assets/`.
Er is geen installatie of ontwikkelserver nodig.

De demo in een enkel HTML-bestand opnieuw maken met Node.js:

```sh
node build.mjs ./just-grow-v13-standalone.html
```

De uitvoer bevat alle pagina's, afbeeldingen, opmaak en navigatie. Externe
bestemmingen zoals YouTube, Spotify en Just Grow Academie vereisen internet.
